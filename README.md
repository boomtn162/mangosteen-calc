# mangosteen-calc

POS สำหรับกลุ่มมังคุด — บันทึกใบเสร็จ, ประวัติ/รายงาน และตั้งค่าราคาต่อเบอร์ อยู่ในไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไรเพิ่ม

ข้อมูลถูกเก็บไว้ในเครื่อง/เบราว์เซอร์ของผู้ใช้ (localStorage) และสามารถซิงค์ขึ้น Google Sheets ได้จากหน้าตั้งค่า

## เปิดใช้งานผ่านเว็บ (GitHub Pages)

1. ไปที่ **Settings → Pages** ของ repo นี้
2. ที่ **Source** เลือก **Deploy from a branch**
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอสักครู่ GitHub จะให้ลิงก์เว็บไซต์ เช่น `https://<username>.github.io/mangosteen-calc/`

หลังจากเปิดใช้งานครั้งแรกแล้ว ทุกครั้งที่ push โค้ดใหม่เข้า `main` เว็บไซต์จะอัปเดตให้อัตโนมัติ

## เปิดใช้งานบนเครื่อง

ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดในเบราว์เซอร์ได้โดยตรง (ทำงานแบบออฟไลน์ผ่าน localStorage)
